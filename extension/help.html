X 评论助手

普通用户，只要这三步

  1. 在工具栏打开插件，进入「模型设置」。
  2. 选 API 服务商，填自己的 Key，读取或填写模型名称，再保存。
  3. 刷新 X，从原帖点回复，再点「生成四条回复」，挑选、修改并自行发送。

云 API 直接从浏览器调用，不需要 Node、终端、本机服务、扩展 ID 或配对码。尚未上架商店，因此 ZIP 需解压后通过「加载已解压的扩展」安装。

密钥保存

直连模式的 API Key 加密保存在当前浏览器，页面和内容脚本不能读取，不进行浏览器同步。它不是系统钥匙串，不能防御已被控制的浏览器或用户资料。不要分享整个浏览器资料；换设备需要重新填写。

可选：本地 Agent

浏览器扩展不能直接启动电脑里的 Codex 或 Claude Code。只有选择本地 Agent 时，才需要另外启动可选桥接，并明确配置这个浏览器的扩展 ID。API 用户可以忽略这些步骤。

本地模型

先在 Ollama 或 LM Studio 加载模型并启动本机服务，再在「本地模型」填写实际回环地址并选择模型。插件不负责下载模型。

回复与媒体

只有明确点击才会生成，插件不自动发评论。图片只交给已适配视觉的型号；视频最多读取封面，无法据此了解整段剧情。请检查回复事实及语境再发送。
